# Expert Systems - final project
Student project made in Python and using the following libraries: numpy, skfuzzy, matplotlib, tkinter.

PROJEKT NA ZALICZENIE PRZEDMIOTU SYSTEMY EKSPERTOWE  
AUTOR: Michał Pamięta  
TEMAT PROJEKTU  
System monitorowania liczby osób w pomieszczeniu na podstawie odczytów z czujników

Program wykorzystuje system rozmyty do analizy danych sensorycznych (temperatura, światło, dźwięk, ruch) i przewiduje liczbę osób w pokoju na podstawie ustalonych reguł logicznych. Wynik wyświetlany jest jako liczba naturalna oraz wizualizacja funkcji przynależności (opcjonalnie).
