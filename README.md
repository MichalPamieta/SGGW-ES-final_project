# Expert Systems - final project
Student project made in Python and using numpy, skfuzzy, matplotlib, tkinter libraries.

PROJEKT NA ZALICZENIE PRZEDMIOTU SYSTEMY EKSPERTOWE
AUTOR: Michał Pamięta
TEMAT PROJEKTU
System monitorowania liczby osób w pomieszczeniu na podstawie odczytów z czujników

Aplikacja wykorzystuje system rozmyty do analizy danych sensorycznych (temperatura, światło, dźwięk, ruch) i przewiduje liczbę osób w pokoju na podstawie ustalonych reguł logicznych. Wynik wyświetlany jest jako liczba naturalna oraz wizualizacja funkcji przynależności (opcjonalnie).
